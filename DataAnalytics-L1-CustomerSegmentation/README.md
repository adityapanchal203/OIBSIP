# Customer Segmentation

## OIBSIP Data Analytics Internship – Task 2

### Project Overview

This project focuses on customer segmentation using retail transaction data.

The purpose is to analyze customer purchasing behaviour and group customers based on their spending and purchase patterns.

### Project Objective

The main objectives are:

- Understand customer purchasing behaviour
- Calculate customer-level sales information
- Identify different customer groups
- Visualize customer segments
- Find useful patterns from the transaction data

### Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

### Project Files

- `AdityaPanchal_Task2_CustomerSegmentation.ipynb` – Jupyter Notebook containing the analysis
- `retail_sales_transactions_cleaned.csv` – Cleaned transaction dataset

### Analysis

The project uses retail transaction data to create customer-level information and identify customer segments based on their purchasing behaviour.
