# Customer Segmentation

## OIBSIP Data Analytics Internship – Task 2

## Project Overview

This project focuses on customer segmentation using retail transaction data.

The purpose of the project is to analyze customer purchasing behaviour and identify different customer groups based on their spending and purchase patterns.

## Project Objective

- Understand customer purchasing behaviour
- Calculate customer-level sales information
- Analyze customer spending patterns
- Identify different customer groups
- Visualize customer segments
- Find useful patterns from the transaction data

## Analysis Performed

The transaction data was analyzed at the customer level to understand purchasing behaviour.

The analysis includes:

- Grouping transactions by customer
- Calculating customer-level sales information
- Analyzing total spending
- Studying purchase quantities and transaction patterns
- Identifying different customer segments
- Visualizing customer purchasing behaviour

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

- `AdityaPanchal_Task2_CustomerSegmentation.ipynb` – Jupyter Notebook containing the analysis
- `data/retail_sales_transactions_cleaned.csv` – Cleaned retail transaction dataset

## Project Outcome

The project provides an understanding of different customer purchasing patterns.

Customer segmentation can help businesses identify high-value customers, understand purchasing behaviour, and develop more targeted marketing strategies.
